# AI-Based Text Keyword Extractor (Keyword Studio)

A Flask web application that extracts keywords from text using RAKE (Rapid Automatic Keyword Extraction).

## Features
- Text input
- Keyword extraction
- Loading animation
- Empty input validation
- Modern UI

## Technologies Used
- Python
- Flask
- RAKE-NLTK
- HTML
- CSS

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   python app.py

3. Open browser:
   http://127.0.0.1:5000
